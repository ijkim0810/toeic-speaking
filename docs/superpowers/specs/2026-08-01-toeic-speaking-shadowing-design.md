# TOEIC Speaking 섀도잉 연습 도구 — 설계

작성일: 2026-08-01

## 목적
TOEIC 스피킹 연습을 위한 "듣고 따라말하기(섀도잉)" 도구. 재생 버튼을 누르면
원어민 음성으로 문장이 들리고, 사용자는 들으며 따라 연습한다. 발음이 핵심이므로
원어민 수준 음질(ElevenLabs)이 필수.

## 핵심 원칙 (구조)
ElevenLabs를 **실시간 호출하지 않는다.** 문장을 넣으면 **한 번만** 음성(mp3)과
타임스탬프를 생성해 저장하고, 실제 연습 도구는 API 키도 서버도 필요 없는
**순수 정적 웹페이지(PWA)** 로 동작한다.

결과:
- 안드로이드에서 오프라인으로 열림, 설치(PWA) 가능
- 비용은 문장당 1회만 발생 (재생 반복은 무료)
- API 키가 클라이언트에 노출되지 않음

## 구성요소

### A. 생성 스크립트 (Python, 오프라인에서 가끔 실행)
- 입력: `topics/*.txt` — 주제별 파일. 한 줄 = `영어 문장 | 한글 뜻`
- 처리: 각 문장마다 ElevenLabs 호출
  - 영어 → `with-timestamps` 엔드포인트: 원어민 음성 mp3 + **글자별 타임스탬프**
    (다국어 v2 모델, 원어민 보이스)
  - 한글 뜻 → 한국어 음성 mp3
- 출력:
  - `audio/<hash>.mp3` (영어/한글 각각)
  - `manifest.json` — 주제별로 문장 배열. 각 문장: `{ en, ko, enAudio, koAudio, words: [{text, start, end}] }`
- 재실행 시: 이미 생성된 문장(내용 동일)은 건너뛰어 API 비용 낭비 방지 (내용 해시 기준)
- 의존성: 없음(파이썬 표준 라이브러리만, HTTP는 `urllib.request`). API 키는 환경변수 `ELEVENLABS_API_KEY` 로 읽음 (파일에 하드코딩 금지)

### B. 연습 웹페이지 (정적 HTML 1개 + PWA)
- 바닐라 HTML/CSS/JS. 프레임워크 없음.
- `manifest.json` 만 읽어 동작.
- 주제 목록 화면 → 주제 선택 → 재생 화면.
- PWA: `manifest.webmanifest` + 작은 service worker(오디오/manifest 캐시) → 안드로이드
  설치 + 오프라인.

## 재생 흐름 (문장 1개당)
1. **한글** 텍스트 표시 + 한국어 음성 1회 (뜻 먼저 이해)
2. **영어** 텍스트 표시 + 원어민 음성 **5회 반복**. 재생 중 단어가 노래방처럼 순차
   하이라이트 (ElevenLabs 타임스탬프 기반, 이미 말한 단어/현재 단어를 2색으로 구분)
3. **간격**(조절 가능한 쉬는 시간) → 다음 문장 자동 진행

설정(화면에서 조절): 반복 횟수(기본 5), 문장 간 간격 시간.

## 디자인
레퍼런스 이미지 기준:
- 연파랑 그라데이션 둥근 카드
- 위: 큰 영어 문장 + 카라오케 2색 하이라이트
- 아래: 한글 번역
- 우측: 마이크 아이콘 = "현재 문장 다시 듣기" 보조 버튼 (발음 채점 아님)

## 명시적 비목표 (하지 않는 것)
- **마이크로 사용자 발음 채점 안 함** — 음성인식은 별도의 무거운 기능. 이번 범위 밖.
- 실시간 백엔드/서버 없음.
- 네이티브 안드로이드 앱 아님 (PWA로 설치+오프라인 커버).
- 웹에서 문장 직접 추가/편집 없음 (문장 추가는 txt 편집 후 스크립트 재실행).

## 폴더 구조
```
옵시디언_google/toeic-speaking/
  topics/               # 주제별 문장 원본 (사용자 편집)
    daily.txt
  generate.py           # 생성 스크립트 (Python)
  web/
    index.html          # 연습 앱 (단일 페이지)
    manifest.json       # 생성물: 문장/음성/타임스탬프
    audio/              # 생성물: mp3
    manifest.webmanifest
    sw.js               # service worker
  docs/superpowers/specs/
    2026-08-01-toeic-speaking-shadowing-design.md
```

## 검토 후 기각한 대안
- **실시간 백엔드 서버**: 재생마다 API 호출 → 비용·키관리·서버 유지비. 불필요.
- **네이티브 안드로이드 앱**: PWA가 설치+오프라인을 커버. 오버킬.
- **브라우저 기본 TTS**: 원어민 발음 품질 부족. 사용자 요구(발음 핵심) 미충족.

## 검증 포인트
- 생성 스크립트: 동일 내용 재실행 시 재생성 안 함(해시 스킵) 확인용 자체 체크.
- 웹: manifest 로드 → 한글1회→영어5회→간격→다음 순서와 타임스탬프 하이라이트
  동기화가 실제 브라우저에서 동작하는지 확인.
